# Encuesta de Experiencia Gamer (HTML)

Formulario de encuesta interactivo desarrollado en **HTML5** orientado a la recolección de preferencias y hábitos de juego en el sector *gaming*[cite: 10]. Implementa validación nativa, uso de controles diversos de entrada de datos y buenas prácticas de vinculación accesible[cite: 10].

---

## 🚀 Características

- **Variedad de Controles:** Uso de campos de texto, correo electrónico, números con límites (`min` y `max`), menú desplegable (`<select>`), botones de opción (*radio buttons*), casillas de verificación (*checkboxes*) y área de texto.
- **Validación Nativa:** Campos requeridos (`required`) que aseguran el llenado correcto de la información básica.
- **Estructura Accesible:** Vinculación de elementos `<label>` con sus respectivos controles mediante el atributo `for`.
